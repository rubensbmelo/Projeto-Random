# 🎲 Random Number Generator

A simple and elegant web-based tool to generate random numbers within a custom range.

## 🚀 Features
- **Custom Range:** Users can define the minimum and maximum values.
- **Modern UI:** Dark mode design with a responsive layout.
- **Real-time Interaction:** Instant results using JavaScript logic.

## 🛠️ Technologies Used
- **HTML5:** Page structure.
- **CSS3:** Styling and transitions (Google Fonts: Roboto).
- **JavaScript:** Logic for number randomization and validation.
